# KRN-008 - Preparación del entorno Chroot

## 1. Objetivo

Implementar un script para verificar los requisitos de una raíz LFS,
preparar los sistemas de archivos necesarios e ingresar al entorno mediante
Chroot cuando la instalación esté completa.

## 2. Script implementado

Archivo: `scripts/krn-008/preparar-chroot.sh`

El script dispone de tres modos:

- `--check`: verifica los archivos y directorios requeridos sin realizar
  modificaciones. Permite revisar raíces montadas en solo lectura.
- `--mount`: verifica los requisitos y prepara los sistemas de archivos
  necesarios para el Chroot.
- `--chroot`: realiza las verificaciones, prepara los montajes e intenta
  ingresar al entorno LFS.

Si no se indica un modo, se utiliza `--check`.

## 3. Requisitos verificados

El script comprueba la existencia de:

- `/usr/bin/env`
- `/bin/bash`
- `/usr/bin`
- `/usr/sbin`
- `/usr/lib`

También comprueba que la raíz LFS sea un punto de montaje.

Para los modos `--mount` y `--chroot`, exige que la raíz permita escritura
y comprueba las herramientas necesarias del sistema anfitrión.

## 4. Montajes contemplados

El procedimiento prepara los siguientes sistemas de archivos:

- `/dev`, mediante montaje bind.
- `/dev/pts`, mediante el sistema de archivos devpts.
- `/proc`, mediante proc.
- `/sys`, mediante sysfs.
- `/run`, mediante tmpfs.

El script comprueba si los puntos ya están montados para evitar repetir
montajes y contempla la limpieza de los montajes realizados por él cuando
se produce un error durante la preparación.

## 5. Pruebas realizadas

### 5.1. Sintaxis

Comando:

`bash -n scripts/krn-008/preparar-chroot.sh`

Resultado: sin errores de sintaxis.

### 5.2. Verificación de una raíz LFS de referencia

Se utilizó la imagen de Lizzy en `/mnt/revision_lizzy`, montada en solo
lectura.

Resultado:

- `/usr/bin/env`: encontrado.
- `/bin/bash`: encontrado.
- `/usr/bin`: encontrado.
- `/usr/sbin`: encontrado.
- `/usr/lib`: encontrado.

La verificación terminó correctamente y no realizó modificaciones.

### 5.3. Verificación de la partición propia

Se ejecutó el modo `--check` sobre `/mnt/lfs`.

Resultado: se detectaron cinco requisitos faltantes porque la partición
todavía no contiene una instalación LFS.

El script detuvo correctamente el procedimiento.

### 5.4. Prueba del modo --mount

Se ejecutó sobre `/mnt/lfs`.

Resultado: el script detectó los cinco requisitos faltantes y se detuvo
antes de realizar montajes.

Se verificó con `findmnt -R /mnt/lfs` que no se habían creado montajes
adicionales.

### 5.5. Prueba del modo --chroot

Se ejecutó sobre `/mnt/lfs`.

Resultado: el script detectó los cinco requisitos faltantes y se detuvo
antes de intentar ingresar al Chroot.

## 6. Limitaciones de las pruebas

La partición propia `/mnt/lfs`, correspondiente a `/dev/sdc1`, se encuentra
montada con permisos de escritura, pero todavía no contiene una instalación
LFS completa.

Por esta razón, no se realizaron montajes reales ni se validó una sesión
real de Chroot.

La imagen de Lizzy se utilizó únicamente como referencia para comprobar
el modo `--check` y se mantuvo montada en solo lectura.
