# KRN-008 - Preparación del entorno Chroot

## 1. Objetivo

Preparar y verificar el entorno LFS necesario para ingresar mediante Chroot,
comprobando las herramientas esenciales y realizando los montajes requeridos.

## 2. Script implementado

Archivo: `scripts/krn-008/preparar-chroot.sh`

El script cuenta con tres modos:

- `--check`: verifica los requisitos sin realizar montajes.
- `--mount`: verifica los requisitos y prepara los sistemas de archivos virtuales.
- `--chroot`: prepara los montajes e ingresa al entorno LFS.

Por defecto, el script ejecuta `--check`.

## 3. Requisitos previos

La raíz LFS debe contener las herramientas necesarias:

- `/usr/bin/bash`
- `/usr/bin/env`
- `/tools/bin/bash`
- `/tools/bin/gcc`
- `/tools/bin/ld`
- `/tools/bin/as`
- `/usr/lib`

La partición debe estar montada con permisos de escritura.

## 4. Montajes

El script contempla los siguientes montajes:

- `/dev`
- `/dev/pts`
- `/proc`
- `/sys`
- `/run`

También comprueba si los puntos de montaje ya están activos.

## 5. Pruebas realizadas

Se ejecutó la comprobación de sintaxis:

`bash -n scripts/krn-008/preparar-chroot.sh`

Resultado: sin errores de sintaxis.

También se ejecutó:

`sudo LFS=/mnt/lfs scripts/krn-008/preparar-chroot.sh --check`

Resultado: se detectaron siete requisitos faltantes en `/mnt/lfs`.

El script detuvo correctamente el procedimiento y no realizó montajes.
