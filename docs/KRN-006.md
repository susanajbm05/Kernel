# KRN-006 – Preparar particiones, montajes y usuario LFS

## Objetivo

Preparar un disco virtual para Linux From Scratch (LFS), creando sus particiones, configurando los sistemas de archivos, los puntos de montaje y el usuario correspondiente.

## Actividades realizadas

1. Se creó un disco virtual de 20 GB en formato VDI.
2. Se configuró una tabla de particiones GPT.
3. Se creó una partición de 18 GB con sistema de archivos ext4.
4. Se creó una partición de 2 GB para intercambio (swap).
5. Se creó el directorio `/mnt/lfs`.
6. Se montó la partición principal en `/mnt/lfs`.
7. Se activó la partición swap.
8. Se creó el usuario `lfs` y el grupo `lfs`.
9. Se asignó la propiedad del directorio `/mnt/lfs` al usuario `lfs`.
10. Se configuró el montaje automático mediante `/etc/fstab`.
11. Se verificaron los montajes, permisos y particiones.

## Distribución del disco

- `/dev/sdc`: 20 GB.
- `/dev/sdc1`: 18 GB, ext4.
- `/dev/sdc2`: 2 GB, swap.
